## Overview
This is a secure, multi-tenant digital AI companion and personal operating system ("Civilization AI") built with Python, FastAPI, aiogram 3, and PostgreSQL with pgvector. I designed it to act as a deeply integrated personal brain, combining persistent memory, long-term episodic search, strict fact verification, proactive check-ins, social diplomat features, a modular tool registry, and an immersive Svelte-based Telegram Mini App interface. All core intelligence is powered exclusively by the Gemini API, utilizing a rigorous fail-fast architecture, strict database-level isolation via Row-Level Security (RLS), and zero-hallucination protocols.

## Key Features
The backend is structured around a robust 3-Tier Memory model. Tier 1 manages core profile facts and constitutional principles in PostgreSQL, handling emotional overrides deterministically through SQL views rather than trusting the LLM. Tier 2 implements pgvector-based episodic memory with a strict LLM-Judge verification loop, ensuring the AI never hallucinates context. Tier 3 provides a sliding context buffer backed by Redis for fast chat history caching. Security is enforced end-to-end: every table requires a tenant ID and strict RLS policies, ensuring absolute isolation between users. The Telegram integration uses structured Telegram Forums where each topic acts as a specialized bot persona (Foodguide, Job Hunt, Discipline, Settings). An asynchronous outbox pattern handles reliable background tasks via Celery, while the system gracefully manages voice messages, document parsing (TXT/DOCX), automated web summarization with SSRF protection, spaced repetition flashcards, a workout tracker with progressive overload, and an autonomous smart inventory system.

## Tech Stack
**Python 3.11, FastAPI, Supabase / PostgreSQL 15+, pgvector, SQLAlchemy 2.0 (async), Alembic, Celery, Redis, aiogram 3, Google GenAI SDK (Gemini API), Svelte 5, Tailwind CSS**
